# Moto Fácil

Atue como Product Owner, UX Designer e Desenvolvedor Full Stack.

Crie um MVP para uma empresa de aluguel de motocicletas para entregadores (iFood, Uber, Mercado Livre e autônomos).

Objetivo:

Captar leads, apresentar os planos de locação e permitir que o cliente solicite uma análise cadastral.

Tecnologias:

- Next.js

- React

- TypeScript

- TailwindCSS

- Responsivo (Mobile First)

- Sem banco de dados

- Utilizar apenas dados mockados em JSON

Desenvolva apenas as seguintes páginas:

1. HOME

- Banner principal

- Benefícios da locação

- Como funciona

- Modelos de motos

- Planos e preços

- FAQ

- CTA "Quero Alugar uma Moto"

2. MOTOS DISPONÍVEIS

- Cards com foto

- Modelo

- Ano

- Valor semanal

- Valor mensal

- Status disponível

3. PLANOS E VALORES

- Plano semanal

- Plano quinzenal

- Plano mensal

- O que está incluso

4. CADASTRO

Criar formulário multi-etapas:

Etapa 1

- Nome

- CPF

- Telefone

- E-mail

Etapa 2

- Endereço

- CEP

- Cidade

- Estado

Etapa 3

- Tempo como entregador

- Aplicativos utilizados

- Renda mensal

Etapa 4

- Upload CNH

- Upload selfie

- Upload comprovante de residência

5. PÁGINA DE SUCESSO

Mensagem:

"Cadastro enviado com sucesso e está em análise."

6. PAINEL ADMINISTRATIVO SIMPLES

- Total de cadastros

- Total de motos

- Cadastros pendentes

- Cadastros aprovados

Tabela:

- Nome

- CPF

- Data

- Status

Status:

- Pendente

- Aprovado

- Reprovado

Requisitos:

- Gerar arquitetura do projeto

- Criar estrutura de pastas

- Criar componentes reutilizáveis

- Criar wireframe textual das telas

- Implementar todas as páginas

- Utilizar dados mockados

- Não utilizar banco de dados

- Preparar a estrutura para futura integração com APIs e banco de dados

Entregar o projeto completo e organizado como um MVP pronto para publicação.
